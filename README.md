Sou estudante de Ciência da Computação e utilizo este espaço para compartilhar minha trajetória de aprendizado, experiências práticas e projetos desenvolvidos durante minha formação acadêmica.

Este perfil reúne tanto projetos acadêmicos quanto iniciativas desenvolvidas durante minha jornada de aprendizado em programação.

## Projetos da Faculdade

Este espaço também reúne atividades, trabalhos e projetos desenvolvidos durante o curso de **Ciência da Computação**.

O objetivo é documentar minha evolução acadêmica e prática, organizando os exercícios, experimentos e soluções desenvolvidos ao longo das disciplinas.

### Organização dos materiais

A estrutura dos projetos acadêmicos segue uma organização por finalidade:

| Diretório | Descrição |
|---|---|
| `atividades/` | Exercícios e atividades realizados durante as disciplinas. |
| `projetos/` | Projetos acadêmicos e trabalhos práticos. |
| `documentacao/` | Relatórios, registros e materiais complementares. |

### Tecnologias utilizadas

As tecnologias variam conforme os objetivos e requisitos de cada atividade ou projeto.

- Linguagens de programação estudadas;
- Bancos de dados;
- Ferramentas de desenvolvimento;
- Git e GitHub para versionamento e organização dos projetos.

**Acesse os repositórios acadêmicos:** [Projetos e atividades no GitHub](https://github.com/gioribeirro?tab=repositories).
